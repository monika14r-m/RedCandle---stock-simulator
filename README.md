# RedCandle – Stock Market Simulator

RedCandle is a stock market simulation project built for learning and experimentation. It allows users to explore trading concepts, portfolio management, and market behavior in a risk-free environment.

## Overview

This project is designed to help users understand the fundamentals of stock trading through simulation. It provides a simplified environment for testing strategies, tracking portfolio performance, and exploring market dynamics without using real money.

## Features

* Simulated stock buying and selling
* Portfolio tracking
* Profit and loss calculation
* Historical transaction records
* Educational trading environment
* Strategy experimentation

## Purpose

The primary goal of this project is educational learning. It was developed to explore concepts such as:

* Portfolio management
* Risk and reward
* Market fluctuations
* Trade execution logic
* Financial data handling

## Limitations

This project is not intended to represent real-world trading conditions.

The current simulation may not include:

* Brokerage fees
* Taxes and regulatory requirements
* Market slippage
* Liquidity constraints
* Exchange-specific trading rules
* Real-time market execution behavior

As a result, outcomes generated by the simulator may differ significantly from actual trading results.

## Disclaimer

This project is intended solely for educational and learning purposes. It should not be used as financial advice or as a basis for real investment decisions.
